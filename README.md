# QIU Online Ordering System

A full-stack cafeteria pre-ordering system that allows students to browse menu items, place orders online, and skip long queues.

## Features
- Browse menu items
- Add items to cart
- Place orders
- View order history
- Vendor dashboard
- Update order status
- Delete orders
- Online Payment

## Technologies
- Node.js
- Express.js
- MongoDB Atlas
- HTML, CSS, JavaScript
- Render (deployment)
- GitHub (version control)
